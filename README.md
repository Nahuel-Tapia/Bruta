# BRUTA WEB STUDIO ⚡

> **YOUR BUSINESS DESERVES A BETTER WEBSITE.**  
> Plataforma web para agencia y estudio de desarrollo freelance con estética editorial brutalista, rendimiento extremo y herramientas interactivas de alta conversión.

---

## ⚡ Tecnologías & Arquitectura

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vite.dev/)
- **Estilos & Diseño**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Tipografías**: Google Fonts (`Anton`, `Montserrat`, `JetBrains Mono`)
- **Iconografía**: [Lucide React](https://lucide.dev/) + SVG Custom Icons
- **Efectos & Micro-interacciones**: `canvas-confetti`, Spotlight Cards, Drag Slider, Device Sandboxing
- **Integraciones**: GitHub REST API en tiempo real & WhatsApp Direct Automation

---

## 🚀 Funcionalidades Exclusivas

1. **Hub Interactivo de GitHub**:
   - Conexión dinámica con la API pública de GitHub (`@Nahuel-Tapia`)
   - Proyectos reales en producción: *Le Désir Fragancias (Astro/Supabase)*, *Veterinaria Integral*, *Eco Huella*, *E-Commerce Clean Architecture*.
   - Selector interactivo de repositorios y terminal simulado.

2. **Slider Interactivo "Antes vs. Después"**:
   - Comparador visual táctil que demuestra el impacto de un diseño moderno y veloz frente a plantillas obsoletas.

3. **Calculadora de Retorno de Inversión (ROI)**:
   - Estimador interactivo que proyecta el aumento en facturación mensual y anual de una web optimizada.

4. **Simulador Responsive en Tiempo Real**:
   - Vista previa dinámica con conmutador *Desktop (1440px)*, *Tablet (768px)* y *Móvil (390px)*.

5. **Presupuestador de Alcance & Cotizador**:
   - Selección de alcance y adicionales con cálculo instantáneo en **USD / ARS** y generación automática del mensaje para WhatsApp.

6. **Lead Magnet de Auditoría Web Gratuita**:
   - Captura de prospectos que solicitan análisis técnico en video de su sitio actual.

7. **Bio de Autor & Compromisos Técnicos Anti-Riesgo**:
   - Presentación de Nahuel con 3 garantías contractuales (PageSpeed 90+, precio cerrado, revisiones ilimitadas).

## 🛠️ Instalación y Uso Local

```bash
# Clonar el repositorio
git clone https://github.com/Nahuel-Tapia/Bruta.git
cd Bruta

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar build de producción
npm run build
```
